# 整理发票报销助手

按报销周期整理分散票据，辅助跨来源查重、周期归属、分类归档及消费流水核对，生成 Excel 明细及贴图、完整原票副本和 Word 报销说明。

版本 **1.1**。适用于支持 Skill 与本地文件操作的 AI 助手。完整材料生成还需要运行环境实际具备 PDF/OCR、表格和 Word 处理能力；邮箱入口按需连接。

## 使用

将本仓库按所用平台支持的方式导入为 Skill，名称为 `invoice-reimbursement`。提供发票、报销周期和输出位置；已有公司模板、填写规则、流水、历史台账时一并提供。

示例指令：

```text
请使用 invoice-reimbursement 整理 2026 年 10 月的报销材料。
票据来源：我提供的文件或文件夹。
输出位置：我指定的可写目录。
优先使用我提供的公司模板、填写规则及历史台账；缺失信息不要猜测。
先说明需要补查的风险、使用的原始材料、可用方法和验收条件，再执行。
交付 Excel 明细及贴图、完整原票副本、Word 报销说明，并单列待确认项。
没有获取、没有执行或没有验证的内容如实注明，不自动提交报销。
```

具体流程及验收要求见 [SKILL.md](SKILL.md)。

## 本地校验器

Python 3.10 或以上，仅使用标准库。先按 [台账字段说明](references/records.md) 准备结构化 JSON，再运行：

```bash
python3 scripts/check_invoices.py records.json --start 2026-10-01 --end 2026-10-31 --out checks.json
```

报告路径必须是新文件。退出码 `0` 表示本次记录检查没有待复核或冲突，`2` 表示已生成报告但仍有待复核项，`1` 表示输入或文件操作错误。`eligible` 仅表示通过有限字段检查的草稿候选，不代表财务批准或发票验真。

校验器覆盖十进制金额、币种分开汇总、周期依据、票据强标识查重、字段冲突、常见疑似重复消费与历史报销状态。它不收取邮件、不执行 OCR、不读取来源原件、不生成 Excel/Word，也不更新报销状态。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

本版本 37 项合成数据测试通过，并完成 15 条合成记录的独立试用与金额复算。真实邮箱、OCR、公司正式模板、原生 Excel 重算及完整三件套尚未在目标环境完成端到端验证。

## 文件

- `SKILL.md`：技能入口与工作流程。
- `references/records.md`：台账、字段和校验器使用方式。
- `references/template-adapter.md`：公司模板适配与检查要求。
- `scripts/check_invoices.py`：确定性本地校验器。
- `tests/test_check_invoices.py`：合成场景回归测试。

仓库仅包含技能说明、代码与合成测试，不包含真实发票、账号凭据、私人目录配置或个人公司模板。处理真实材料时，应将票据、报销产物和台账放在仓库之外。
